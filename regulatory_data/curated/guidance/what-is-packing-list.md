question: What is a packing list and what does it need to show?

A packing list describes exactly how a shipment is physically packed - how
many cartons or pallets there are, what is inside each one, and the weight
and dimensions of the shipment. Where a commercial invoice answers "what is
this worth", a packing list answers "what is actually in each box".

Customs and freight handlers use it during physical inspection: if an officer
opens a carton to check the shipment, the packing list tells them what they
should find inside without having to open every single box. It also helps
the shipping line calculate freight and plan how the cargo is loaded.

A packing list that does not match the commercial invoice - different
quantities, or items the invoice does not mention - is a common reason a
shipment gets flagged for closer examination, so the two documents need to
agree with each other.
