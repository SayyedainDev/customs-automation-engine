An HS code (Harmonized System code) is a standard number used almost
worldwide to classify exactly what kind of product is being traded. It was
created by the World Customs Organization so that customs authorities in
different countries can identify the same type of goods consistently, no
matter what language or local naming is used.

The first six digits are the same everywhere in the world - that part is the
"Harmonized System" itself. Countries then add extra digits of their own for
more detail: Pakistan's version is called the Pakistan Customs Tariff (PCT)
and uses eight-digit codes, where the last two digits are Pakistan-specific.

The code you use matters a lot, because it is what determines your customs
duty rate, whether any restrictions or extra permits apply, and whether your
goods qualify for a preferential rate under a trade agreement. Classifying a
product under the wrong code - even close ones can have different rates - is
one of the most common causes of disputes with customs, so it is worth
getting confirmed rather than guessed.
