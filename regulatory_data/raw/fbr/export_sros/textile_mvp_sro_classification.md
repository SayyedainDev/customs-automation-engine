## Scope and decision rules

This report classifies all 34 rows recorded from FBR's **Customs Active/Operative Notifications/SROs — Export** page. It was prepared from the local download manifest and the locally available PDFs only. No additional file was downloaded, renamed, moved, deleted, OCR-processed, embedded, or inserted into a database.

- `duplicate_existing_document` takes precedence when the active-page file has the same SHA-256 as an already organized canonical PDF. The canonical PDF may still be relevant or irrelevant; the duplicate row must never create a second ingestion.
- `relevant_to_textile_mvp` means the subject directly covers textile goods or a textile-export facility. Historical, firm-specific, or amendment-chain limits stated below must still be enforced.
- `possibly_relevant` means applicability depends on the selected PCT/product scope or exporter regime.
- `not_relevant_to_textile_mvp` means the subject is outside the current textile scope.
- `needs_manual_review` means the local evidence is insufficient, the SRO identifier is unresolved, or the document is only a draft.

The statuses are routing decisions, not a declaration that every listed notification remains legally effective on 2026-07-22. Only validated, applicable portions of relevant sources should later enter the textile rule engine or vector database.
